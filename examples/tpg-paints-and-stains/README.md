# Example build — TPG Paints & Stains LLC (Arizona)

The first complete Instant Website build, from the real company at
thepaintguysaz.com. Shows the quality bar for every future client.

| File | Page |
|---|---|
| `tpg-paints-mockup.html` | Homepage (predates the locked wireframe; new builds start from `skill/templates/home-wireframe.html`) |
| `painters-scottsdale-az.html` | Area page — Scottsdale (HOA color-submittal angle) |
| `painters-arcadia-az.html` | Area page — Arcadia (painted brick / mid-century angle) |
| `painters-gilbert-az.html` | Area page — Gilbert (chalking builder-stucco angle) |
| `exterior-painting.html` | Flagship service page |
| `assets/` | Real harvested photos (watermark-checked), logo, shared stylesheet |
| `src-assets/` | Raw harvested source images |
| `tpg-paints-mockup.OLD-layout.html` | Archived earlier homepage layout |

Serve locally: `python3 -m http.server 8123 --directory .` → http://localhost:8123/tpg-paints-mockup.html
