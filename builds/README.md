# Instant Website Builder — client builds

Each company mockup is scaffolded here (or in `~/Mockups/` on a machine that
already uses that folder):

```bash
python3 skill/scripts/new_build.py --url https://COMPANY.com --name "Company LLC" --out builds
```

Client trees are gitignored. The skill, wireframe, and TPG example stay in
the repo; live pitches do not.
